Docus 构建于 Nuxt UI 之上，充分利用了 Tailwind CSS v4 和 CSS 变量。Tailwind Variants API 提供了一套灵活且可扩展的主题系统。

::tip{to="https://ui.nuxt.com/getting-started/theme"}
如需全面了解 Nuxt UI 的主题系统，请查阅 Nuxt UI 文档。
::

## 使用 `@theme` 覆盖

你可以在 `@theme` 指令内通过 CSS 变量自定义主题，以定义项目的专属设计令牌，例如字体、颜色和断点。

要覆盖主题，请在项目中创建 `app/app.css` 文件：

```css [app/app.css]
@theme {
  --font-sans: 'Public Sans', sans-serif;

  --breakpoint-3xl: 1920px;

  --color-green-50: #EFFDF5;
  --color-green-100: #D9FBE8;
  --color-green-200: #B3F5D1;
  --color-green-300: #75EDAE;
  --color-green-400: #00DC82;
  --color-green-500: #00C16A;
  --color-green-600: #00A155;
  --color-green-700: #007F45;
  --color-green-800: #016538;
  --color-green-900: #0A5331;
  --color-green-950: #052E16;
}
```

::warning
Docus 会自动导入 `app/app.css` — 你无需将其添加到 `nuxt.config.ts` 的 `css` 数组中，并且**不应**在该文件中包含 `@import "tailwindcss"`，因为 Docus 已为你处理。
::

## 颜色

Docus 使用了一组预配置的颜色别名，用于为组件设置样式，并驱动整个 UI 中的 `color` props。

下面每个徽章代表一个默认别名：

- :u-badge{label="primary" variant="outline"} → 主品牌色，作为组件的默认颜色使用 :br [(默认：绿色)]{.text-xs,text-muted}
- :u-badge{color="secondary" label="secondary" variant="outline"} → 与主色互补的次要颜色 :br [(默认：蓝色)]{.text-xs,text-muted}
- :u-badge{color="success" label="success" variant="outline"} → 用于成功状态 :br [(默认：绿色)]{.text-xs,text-muted}
- :u-badge{color="info" label="info" variant="outline"} → 用于信息提示状态 :br [(默认：蓝色)]{.text-xs,text-muted}
- :u-badge{color="warning" label="warning" variant="outline"} → 用于警告状态 :br [(默认：黄色)]{.text-xs,text-muted}
- :u-badge{color="error" label="error" variant="outline"} → 用于表单错误校验状态 :br [(默认：红色)]{.text-xs,text-muted}
- :u-badge{color="neutral" label="neutral" variant="outline"} → 用于背景、文本等的中性色 :br [(默认：石板灰)]{.text-xs,text-muted}

你可以在 `app.config.ts` 文件的 `ui.colors` 键下全局自定义这些颜色：

```ts [app.config.ts]
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'blue',
      neutral: 'zinc'
    }
  }
})
```

## 组件

除颜色之外，所有 [Nuxt UI 组件](https://ui.nuxt.com/components)都可以通过 `app.config.ts` 进行全局主题化。

你可以使用与组件内部主题对象相同的结构 (展示在[每个组件页面的末尾](https://ui.nuxt.com/components/card#theme))来覆盖任意外观。

例如，要更改所有按钮的字重：

```ts [app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        base: 'font-bold'
      }
    }
  }
})
```

在这个例子中，`font-bold` 类会覆盖所有按钮上默认的 `font-medium` 类。

::note{to="https://ui.nuxt.com/components/button#theme"}
要探索每个组件可用的主题选项，请参阅各自 Nuxt UI 文档页面中的**主题**部分。
::

## Docus 子组件

Docus 在内部使用了若干 Nuxt UI 组件来实现导航、目录和子导航。你可以通过 `app.config.ts` 中的 `defaultVariants` 键自定义它们的默认变体，而无需覆盖整个组件。

以下组件可配置：

| 组件 | 键 | 默认值 |
|---|---|---|
| [ContentToc](https://ui.nuxt.com/components/content-toc) | `ui.contentToc` | `highlight: true` |
| [ContentNavigation](https://ui.nuxt.com/components/content-navigation) | `ui.contentNavigation` | `variant: 'link'`, `highlight: true` |
| [NavigationMenu](https://ui.nuxt.com/components/navigation-menu) | `ui.navigationMenu` | `variant: 'pill'`, `highlight: true` |

例如，要将目录的高亮样式改为 `circuit`，并将侧边栏导航变体切换为 `pill`:

```ts [app.config.ts]
export default defineAppConfig({
  ui: {
    contentToc: {
      defaultVariants: {
        highlightVariant: 'circuit',
        highlightColor: 'secondary'
      }
    },
    contentNavigation: {
      defaultVariants: {
        variant: 'pill',
        highlight: false
      }
    }
  }
})
```

每个组件支持以下变体选项：

- **`highlight`** — 是否显示激活指示线 (`true` 或 `false`)
- **`highlightColor`** — 指示线的颜色 (`primary`、`secondary`、`neutral` 等)
- **`variant`** — 视觉样式 (适用时为 `pill` 或 `link`)
- **`highlightVariant`** — 指示线样式 (`straight` 或 `circuit`，仅 ContentToc)
- **`color`** — 激活链接的基础颜色
