Docus 构建于 Nuxt 4 之上，Nuxt 4 提供了灵活的组件层系统，允许你在自己的应用中重新定义特定组件，从而覆盖部分 UI。这让你无需触碰核心主题，即可轻松完全自定义文档的视觉外观和行为。

要覆盖某个组件，只需在 `components/` 目录中创建同名的 Vue 文件。Docus 会自动使用你的版本，而不是默认版本。

## 应用页头

你可以通过覆盖以下组件来自定义页头的不同部分：

### `AppHeaderLogo`

对于简单的调整，比如更改 logo 尺寸，你可以直接使用 `app.config.ts` 中的 `logo.class` 选项 (例如 `class: 'h-8'`)，而无需覆盖组件。

要完全替换页头中的默认 logo，请创建 `components/AppHeaderLogo.vue` 文件。你的组件将替换 Docus 主题提供的默认组件。你可以使用 `useLogoAssets()` 组合式函数来保留带有复制和下载操作的右键上下文菜单。

## 文档页面

你还可以自定义文档页面的页头以及左右两个侧边栏。

### `DocsPageHeaderLinks`

在文档页面页头的右侧，Docus 的默认行为是显示一个下拉菜单，其中包含与当前页面 Markdown 源文件相关的快捷操作。它允许文档读者：

- **复制直达链接**到剪贴板，指向原始 `.md` 文件。
- 在新浏览器标签页中**查看 Markdown 源文件**。
- **在 ChatGPT 或 Claude 中打开页面内容**，并预填一段用于分析该 Markdown 文件的提示词。

这些操作对贡献者、读者或 AI 辅助工作流尤其有用，但你也可以创建自己的 `components/DocsPageHeaderLinks.vue` 组件来覆盖它。

## 自定义图标

Docus 使用 [Nuxt Icon](https://github.com/nuxt/icon) 搭配 [Iconify](https://iconify.design/) 提供者，让你开箱即用地访问数千个图标 (例如 `i-lucide-arrow-right`、`i-simple-icons-github`)。

要添加你自己的图标，请将 SVG 文件放到应用的 `assets/icons/` 目录中。它们会自动以 `custom` 前缀注册，并可在项目中的任何位置使用。

```
assets/
  icons/
    my-logo.svg
```

之后你可以使用 `i-custom:` 前缀来引用它们：

```md [content/getting-started.md]
---
navigation:
  icon: i-custom:my-logo
---
```

```ts [app.config.ts]
export default defineAppConfig({
  toc: {
    bottom: {
      links: [{
        icon: 'i-custom:my-logo',
        label: '预览',
        to: '/preview'
      }]
    }
  }
})
```

```vue [components/MyComponent.vue]
<template>
  <UIcon name="i-custom:my-logo" />
</template>
```

::tip{to="https://iconify.design/docs/icons/icon-set-basics.html"}
SVG 文件的填充和描边应使用 `currentColor`，以便图标能够适应文本颜色。
::
