Docus 提供多种自定义选项，以满足你的不同需求。

- 你可以将它作为一个完整的网站解决方案，同时包含落地页和文档两个部分
- 也可以将文档功能嵌入到你自己的 Nuxt 应用中，同时完全掌控其他所有部分 (得益于 [Nuxt 层特性](https://nuxt.com/docs/4.x/getting-started/layers))。

## 落地页

落地页是访客在你站点根路径 `/` 看到的第一个页面。

### `Markdown`(默认)

默认情况下，落地页对应 `content/index.md` 文件。

Docus 会自动：

- 为 `content/index.md` 文件创建一个 `landing` 内容集合
- 注册 `/` 路由来渲染你的 Markdown 落地页

::tip{to="https://ui.nuxt.com/docs/components"}
`MDC` 语法让你能够在 `.md` 文件中使用 Vue 组件，包括 slot 和 props。你可以在 Markdown 中使用任意 Nuxt UI 组件来构建落地页。
::

### `Vue`(自定义)

由于 Docus 是一个层，你可以通过在 `app/pages/index.vue`(i18n 场景下为 `app/pages/[[lang]]/index.vue`)创建 Vue 页面来完全自定义落地页。这让你能够借助 Vue 组件、自定义布局和高级交互实现完全掌控。

在这种情况下，Docus 会：

- 不再创建 `landing` 集合
- 使用原生 Nuxt 路由，并将 `index.vue` 视为你的首页

::note
这种自动检测机制同时适用于单语言和多语言 (i18n) 配置。
::

### 组件

MDC 提供了专门的语法，让你可以轻松地在内容中使用 Vue 组件：

```mdc [content/index.md]
:::u-page-feature
:::
```

### Slot

Slot 可以接收文本内容或其他组件。

- **默认 slot** 会直接渲染在组件内部，或通过 `#default` 指定。
- **具名 slot** 使用 `#` 符号加 slot 名称来定义。

```mdc [index.md]
:::u-page-feature
  #title
  Nuxt 4
  
  #description
  由 Nuxt 4 驱动，带来最佳性能与 SEO 表现。
:::
```

### Props

Props 可以通过行内语法或组件块内的 YAML frontmatter 传递：

::tabs
  :::tabs-item{icon="i-lucide-braces" label="行内"}
  ```mdc [index.md]
  :::u-page-feature{icon="i-simple-icons-nuxt" to="https://nuxt.com"}
    #title
    Nuxt 4
    
    #description
    由 Nuxt 4 驱动，带来最佳性能与 SEO 表现。
  :::
  ```
  :::

  :::tabs-item{icon="i-lucide-code" label="YAML"}
  ```mdc [index.md]
  :::u-page-feature
    ---
    icon: i-simple-icons-nuxt
    to: https://nuxt.com
    ---
    #title
    Nuxt 4
    
    #description
    由 Nuxt 4 驱动，带来最佳性能与 SEO 表现。
  :::
  ```
  :::
::

::note{to="https://content.nuxt.com"}
更多关于 MDC 语法的细节，请查阅 Nuxt Content 文档
::

## 文档页面

::tip
内容文件与站点页面之间是一一对应的关系。`content/` 文件夹中的每个 Markdown 页面都直接映射到一个页面路由。
::

### 不使用 docs 文件夹

要开始使用，只需在 `content/` 目录中编辑或添加 `.md` 文件，页面便会随之更新。Docus 会自动处理路由、导航和全文搜索。

```bash
content/
├── index.md              # 落地页 → /
├── getting-started.md    # 文档 → /getting-started
└── guide/
    └── introduction.md   # 文档 → /guide/introduction
```

### 使用 docs 文件夹

你也可以选择将文档文件组织在 `docs/` 子文件夹中。当 Docus 检测到 `content/` 目录中存在 `docs/` 文件夹时，会自动为所有文档 URL 添加 `/docs` 前缀。

```bash
content/
├── index.md                  # 落地页 → /
└── docs/
    ├── getting-started.md    # 文档 → /docs/getting-started
    └── guide/
        └── introduction.md   # 文档 → /docs/guide/introduction
```

::tip
当你希望将 Docus 作为嵌入式文档与其他自定义页面一起使用时，这一点尤其有用。你可以在根级别创建博客、联系页、定价页等额外页面或任意其他自定义内容，同时将文档统一组织在 `/docs` 下。
::

### 混合内容

由于 Docus 是一个 Nuxt 层，你可以将 Markdown 文件与自定义 Vue 页面结合使用：

```bash
├── app/
│   └── pages/
│       ├── pricing.vue       # 自定义定价页 → /pricing
│       └── contact.vue       # 自定义联系页 → /contact
└── content/
    ├── index.md              # 落地页 → /
    └── blog.md               # 博客页面 → /blog
    └── docs/                 # 文档 → /docs/*
        ├── getting-started.md
        └── api/
            └── reference.md
```

这种结构让你能够灵活地使用 Docus 构建完整的网站：用 Markdown 编写文档，用 Vue 页面实现博客、仪表盘或任意交互式页面等自定义功能。

### Frontmatter

`content/` 文件夹中的每个文件都以页面顶部的 `---` 语法开始。它对应文件的 frontmatter，是基于 Markdown 的 CMS 为页面提供元数据的通用约定。

::tabs
  :::tabs-item{icon="i-lucide-code" label="代码"}
  ```md [content/getting-started/edition.md]
  ---
  title：'版本'
  description：'了解如何编写你的文档。'
  ---

  <!-- 纯 Markdown 编写的页面内容 -->
  ```
  :::

  :::tabs-item{icon="i-lucide-eye" label="预览"}
  ![Frontmatter 的标题与描述](/documentation/frontmatter-preview-title-description.png)
  :::
::

### 参数

`/content` 目录中的页面在 Nuxt Content 中被定义为 [page](https://content.nuxt.com/docs/collections/types#page-type) 类型。它们都遵循相同的结构，可使用以下 frontmatter 键：

|               |                                          |                                                                                                                               |   |
| ------------- | ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | - |
| 键            | 类型                                     | 描述                                                                                                                          |   |
| `title`       | `string`                                 | 页面标题。显示在页面顶部。如果未提供 `seo` 键，则用作 SEO 标题。                                                               |   |
| `description` | `string`                                 | 页面描述。显示在页面顶部标题下方。如果未提供 `seo` 键，则用作 SEO 描述。                                                       |   |
| `navigation`  | `boolean`                                | 定义页面是否包含在左侧导航中。                                                                                                |   |
| `layout`      | `string`                                 | 更改页面的 Nuxt 布局 (默认为 Docus 定义的 `docs`)。                                                                           |   |
| `seo`         | `{ title: string, description: string }` | 页面的 SEO 元信息。                                                                                                           |   |
