## Nuxt 应用

Docus 构建于 **Nuxt 4** 之上，这意味着你的文档项目就是一个完整的 Nuxt 应用。当你使用 **Docus CLI** 脚手架创建项目时，它会默认添加一个层，让你拥有标准 Nuxt 应用的全部灵活性。

默认情况下，Docus 启动模板只包含 `content/` 和 `public/` 文件夹以及一个 `package.json`。这已足够让你开始编写文档。你还可以更进一步，使用 Nuxt 项目的任何特性，从 [nuxt.config.ts](https://nuxt.com/docs/guide/directory-structure/nuxt-config) 到[组件](https://nuxt.com/docs/guide/directory-structure/nuxt-config)或[插件](https://nuxt.com/docs/guide/directory-structure/plugins)。

::note
你可以使用 Nuxt 4 提供的[新目录结构](https://nuxt.com/docs/getting-started/upgrade#new-directory-structure)(由 [compatibility version 4]() 提供)。所有与前端应用相关的文件都放在 `app/` 文件夹中，让组织更清晰，IDE 性能更好。
::

## Nuxt 模块

想为你的文档增强自定义功能？你可以像在任何 Nuxt 应用中一样安装并配置 [Nuxt 模块](https://nuxt.com/modules)。

要为你的文档添加 [Vercel Web Analytics](https://vercel.com/docs/analytics):

::steps
### 安装 `@vercel/analytics`

```bash [Terminal]
npm install @vercel/analytics
```

### 在 `nuxt.config.ts` 中启用 Web Analytics

对于 Nuxt，你可以使用行内模块声明来开启 Vercel Analytics，无需额外设置：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@vercel/analytics/nuxt/module'],
})
```
::

## 自定义组件

借助 `Nuxt Content` 和 `Nuxt UI` 的强大能力，以及 `MDC` 语法的帮助，你可以直接在 Markdown 中使用 [Nuxt UI 组件](/zh-cn/essentials/components)，无需任何额外配置。

不过，你并不局限于预置组件。Docus 让你可以轻松地在 Nuxt 应用中创建自己的 Vue 组件，并在内容中使用它们。

下面是一个简单的示例：在 Nuxt 应用的 `components` 文件夹中创建自定义的 `BrowserFrame` 组件，并将其集成到 Markdown 中：

::tabs
  :::tabs-item{.my-5 icon="i-lucide-code" label="代码"}
  ```vue [components/content/BrowserFrame.vue]
  <script setup lang="ts">
  defineProps<{
    title?: string
  }>()
  </script>

  <template>
    <div class="w-fit rounded-xl border border-muted bg-accented shadow-md overflow-hidden px-2 pb-2">
      <div class="flex justify-between items-center px-2 py-2 bg-accented border-accented border-b">
        <div class="flex items-center gap-2">
          <span class="w-3 h-3 bg-red-500 rounded-full" />
          <span class="w-3 h-3 bg-yellow-500 rounded-full" />
          <span class="w-3 h-3 bg-green-500 rounded-full" />
        </div>
        <div class="text-muted">
          {{ title }}
        </div>
      </div>
      <slot mdc-unwrap="p" />
    </div>
  </template>
  ```
  :::

  :::tabs-item{icon="i-simple-icons-markdown" label="Markdown"}
  ```mdc
  ::browser-frame{title="阿尔卑斯山"}
  ![山脉风景](/mountains.webp)
  ::
  ```
  :::

  :::tabs-item{icon="i-lucide-eye" label="预览"}
    ::::browser-frame{title="阿尔卑斯山"}
    ![山脉风景](/documentation/mountains.webp)
    ::::
  :::
::

这种方式让你能够使用 Markdown 创建由 Nuxt 组件驱动的动态文档。

## Vue 页面

除了 Markdown 页面，你还可以在 `pages/` 目录中创建 Vue 页面。

```vue [pages/hello.vue]
<template>
  <div>
    <h1>你好</h1>
  </div>
</template>
```

你也可以使用 `definePageMeta` 函数设置页面元信息，例如使用 `default` 或 `docs` 布局，或者定义页面是否显示页头和页脚：

```vue [pages/hello.vue]
<script setup lang="ts">
definePageMeta({
  layout: 'default',
  // 移除页头
  header: false,
  // 移除页脚
  footer: false,
})
</script>
```

## 自定义布局

Docus 使用两种布局：

- `default` 布局，用于落地页和自定义 Vue 页面
- `docs` 布局，用于文档页面

如果你想使用不同的布局，可以在 `app/layouts/` 目录中创建：

```vue [app/layouts/custom.vue]
<template>
  <main class="custom-layout">
    <slot />
  </main>
</template>
```
