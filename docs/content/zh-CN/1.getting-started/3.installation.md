## `create-docus` CLI

::steps
### 创建你的 docs 目录

使用 `create-docus` CLI 创建一个新的 Docus 项目：

```bash [Terminal]
npx create-docus my-docs
```

你可以在两种模板之间选择：

- `default`：用于单语言文档的基础 Docus 配置
- `i18n`：包含国际化支持，适用于多语言文档

```bash [Terminal]
# 使用 i18n 模板创建
npx create-docus my-docs -t i18n
```

我们推荐使用 `npm` 作为包管理器。

### 以开发模式启动 docs 服务器

进入你的 docs 目录，并以开发模式启动 docs 服务器：

```bash [Terminal]
cd my-docs
npm run dev
```

文档的本地预览地址为 <http://localhost:3000>

### 编写你的文档

前往[编写](/zh-cn/concepts/edition)章节，了解如何撰写文档。
::

## AI 助手技能 (Skill)

通过为你的 AI 助手 (Cursor、Claude 等) 添加专业知识，快速上手 Docus：

```bash [Terminal]
npx skills add https://docus.dev
```

该技能可为你的 AI 助手提供以下内容，帮助你更快地创建文档：

- 使用 Docus 编写文档的最佳实践
- MDC 组件用法与开箱即用的模板
- 写作规范与内容结构模式
- 配置与自定义技巧

安装之后，AI 助手就能帮你搭建新的文档项目、生成结构规范的页面，并按照 Docus 最佳实践撰写内容。

::tip{to="/zh-cn/ai/skills"}
你也可以从自己的 Docus 站点发布技能。进一步了解 Agent Skills。
::

## 层集成

Docus 采用**基于 Nuxt 层的方式**，你可以直接在 `nuxt.config.ts` 中通过 `extends: ['docus']` 扩展 Docus 层：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['docus']
})
```
