**Nuxt Studio** 模块是一个基于浏览器的界面，可直接在生产环境中编辑你的 Nuxt Content 网站。通过已部署站点上的 GitHub、GitLab 或 Google 身份认证即可访问，无需任何本地开发工具就能开始管理内容。

::tip{to="https://nuxt.studio/introduction"}
浏览 Nuxt Studio 文档，了解如何安装该模块。
::

:video{controls loop src="https://res.cloudinary.com/nuxt/video/upload/v1767647099/studio/studio-demo_eiofld.mp4"}

**studio 编辑器**让你完全在浏览器中、在生产网站上管理内容。无需本地开发工具、Git 命令或终端访问。对于希望在熟悉环境中编辑并预览更改的内容团队来说，它是理想之选。

## 在生产环境中可视化编辑你的 Nuxt Content 网站

Nuxt Studio 为由 Nuxt Content 驱动的网站提供**生产环境中的可视化编辑**。

Studio 最初是独立的付费平台，如今已成为一个**免费、开源、可自托管的 Nuxt 模块**。它让开发者和非技术编辑在内的整个团队都能安全地创建和更新内容，无需离开线上网站。

## 当前功能

### ✨ **TipTap 可视化编辑器**

富文本 Markdown 编辑器，完整支持 MDC 组件。

### 💻 **Monaco 代码编辑器**

面向 Markdown(MDC)、YAML 和 JSON 文件的高级代码编辑器，适合直接编辑原始代码。

### 📝 **表单编辑器**

基于集合 schema 自动生成的表单，用于编辑 YAML、JSON 和 frontmatter。

### 🎨  **Vue 组件 props 编辑器**

可视化界面，直接在编辑器中修改 Vue 组件的 props。

### 🔄 **实时预览**

即时在生产网站上预览内容更改。

### 🔐 **多提供方身份认证**

支持 GitHub、GitLab 和 Google 的安全 OAuth 认证。

### 🔑 **自定义身份认证**

提供工具以实现自定义认证流程 (密码、SSO、LDAP 等)。

### 📝 **文件管理**

在 [content/]{.s2} 目录中创建、编辑、重命名和删除内容文件。

### 🖼 **媒体管理**

集中式媒体库，支持 JPEG、PNG、GIF、WebP、AVIF、SVG 等格式。

### 🌳 **Git 集成**

直接在生产环境中提交内容更改，并交由你的 CI/CD 流水线完成部署。

### 🚀 **开发模式**

使用 Studio 界面直接编辑本地文件系统中的内容和媒体文件。

### 🌍 **国际化**

完整的 i18n 支持，涵盖 17 种语言:AR、BG、DE、EN、ES、FA、FI、FR、ID、IT、JA、NL、PL、PT-BR、UA、ZH、ZH-TW。
