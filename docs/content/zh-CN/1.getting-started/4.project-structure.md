## 整体结构

Docus 是一个 **Nuxt 层**，在标准 Nuxt 应用之上扩展了文档功能。这让你拥有完整 Nuxt 项目的灵活性。

当你使用 `npx create-docus my-docs` 创建新的 Docus 项目时，会得到：

```bash
my-docs/
├── content/             # 你的 Markdown 内容
│   ├── index.md         # 首页
│   └── docs/            # 文档页面
├── public/              # 静态资源
└── package.json         # 依赖与脚本
```

你仍然可以使用传统 Nuxt 项目的任意功能或文件：

```bash
my-docs/
├── nuxt.config.ts       # Nuxt 配置(添加额外的模块、组件等)
├── app/                 # app 目录
    ├── app.config.ts    # App configuration
│   ├── components/      # 组件(添加你自己的组件)
│   ├── layouts/         # 布局(添加你自己的布局)
│   └── pages/           # 页面(添加你自己的页面)
└── server/              # 服务端代码(添加你自己的服务端代码)
```

### `content/` 目录

这里是使用 Markdown [编写页面](/zh-cn/concepts/edition)的地方。Docus 会根据你的文件结构自动生成路由。

**单语言结构：**

```bash
content/
├── index.md              # 落地页 (/)
├── getting-started.md    # 文档页面 (/getting-started)
└── guide/
    ├── introduction.md   # 文档页面 (/guide/introduction)
    └── configuration.md  # 文档页面 (/guide/configuration)
```

::tip{to="/zh-cn/concepts/edition"}
你可以将文档文件单独放在 `docs/` 子文件夹中，使其可通过 `/docs` 路由访问。此外，如有需要，你还可以使用自定义 Vue 页面来覆盖落地页。
::

**多语言结构 (配合 i18n)：**

```bash
content/
├── en/
│   ├── index.md             # 英文落地页 (/en)
│   └── guide/
│       └── introduction.md  # 文档页面 (/en/guide/introduction)
└── fr/
    ├── index.md             # 法文落地页 (/fr)
    └── guide/
        └── introduction.md  # 文档页面 (/fr/guide/introduction)
```

::tip{to="/zh-cn/concepts/internationalization"}
更多关于 i18n 的信息请查看国际化章节。
::

### `public/` 目录

`public/` 目录中的文件会在根路径下提供服务，且不会被构建过程修改。你可以将图片、图标及其他静态资源放在这里。

### `package.json`

该文件包含应用的所有依赖与脚本。Docus 应用的 `package.json`
非常精简，如下所示：

```json [package.json]
{
  "name": "my-docs",
  "scripts": {
    "build": "nuxt build --extends docus",
    "dev": "nuxt dev --extends docus",
  },
  "dependencies": {
    "docus": "latest",
    "better-sqlite3": "^12.2.0",
    "nuxt": "^4.0.0"
  }
}
```

### `nuxt.config.ts`

*启动 Docus 应用并不强制要求此文件。*

你可以在 Nuxt 配置文件中添加额外的模块：

```typescript [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@vercel/analytics/nuxt/module']
})
```

### `app.config.ts`

*启动 Docus 应用并不强制要求此文件。*

::warning
如果想覆盖应用配置，你需要先设置 `nuxt.config.ts`。
::

在这里你可以[配置 Docus](/zh-cn/concepts/configuration)，以匹配你的品牌、处理 SEO、设置语言环境，并调整链接与社交信息。

```ts [app.config.ts]
export default defineAppConfig({
  docus: {
    locale: 'en', // 设置你的单语言区域
  },
  seo: {
    title: '我的文档',
    description: '我的精彩文档',
  },
  // ... 其他配置
})
```

## 完整的 Nuxt 项目能力

由于 Docus 是一个 Nuxt 层，你可以使用标准 Nuxt 项目的**任意功能**:

::warning
如果想用 Nuxt 文件覆盖你的应用，你需要先设置 `nuxt.config.ts`。如果未创建 Nuxt 配置，更改将不会生效。
::

```bash
my-docs/
├── app/                 # app 目录(可选)
│   ├── app.config.ts    # App configuration
│   ├── app.css          # 自定义主题(由 Docus 自动导入)
│   ├── components/      # 自定义 Vue 组件
│   ├── layouts/         # 自定义布局
│   ├── pages/           # 自定义 Vue 页面(在 content 之外)
│   ├── composables/     # Vue 组合式函数
│   └── middleware/      # 路由中间件
├── server/              # 服务端代码
│   └── api/             # API 路由
├── plugins/             # Nuxt 插件
├── middleware/          # 全局中间件
└── modules/             # 自定义 Nuxt 模块
```

::tip{to="/zh-cn/concepts/nuxt"}
这种基于层的方式让你既能拥有整个 Nuxt 生态的能力，又能保持以文档为核心。
::
