## `pnpm` 问题

### 批准构建脚本

如果在使用 `pnpm` 时遇到构建或开发错误，尤其是与 `better-sqlite3` 依赖相关的错误，你可能需要批准某些包参与构建。

运行以下命令来批准包的构建：

```bash [Terminal]
pnpm approve-builds
```

出现提示时，从包列表中选择 `better-sqlite3` 和 `sharp`，批准它们参与构建。

### 启用 shamefully hoisting (兼容模式)

如果你看到诸如 `Can't resolve 'tailwindcss'` 或 `Can't resolve '@nuxt/ui'` 的错误，并不一定需要手动引入它们，只需应用扁平化的 `node_modules` 布局 (与 npm 或 yarn 类似)。

创建一个 `.npmrc` 文件并写入以下内容，即可启用兼容模式：

```bash [.npmrc]
shamefully-hoist=true
```
