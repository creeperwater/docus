欢迎来到 **Docus**，一个基于 [Nuxt UI](https://ui.nuxt.com) 构建的完整文档解决方案。

## Docus 是什么？

Docus 是基于 [UI documentation template](https://docs-template.nuxt.dev/) 的主题。视觉风格开箱即用，你只需专注于使用 [Nuxt Content](https://content.nuxt.com) 提供的 Markdown 与 [MDC 语法](https://content.nuxt.com/docs/files/markdown#mdc-syntax)撰写内容。

## 核心特性

该主题包含一系列旨在改进文档管理的功能：

- **由** **[Nuxt 4](https://nuxt.com)** **驱动**：采用最新的 Nuxt 框架，性能卓越。
- **基于** **[Nuxt UI](https://ui.nuxt.com)** **构建**：集成了一套完整的 UI 组件。
- **通过** **[Nuxt Content](https://content.nuxt.com)** **使用** **[MDC 语法](https://content.nuxt.com/usage/markdown)**：支持在 Markdown 中集成组件，实现动态内容。
- **兼容** **[Nuxt Studio](https://docus.dev/zh-cn/getting-started/studio)**：以可视化方式撰写和编辑内容，无需任何 Markdown 知识！
- **自动生成侧边栏导航**：根据内容结构自动生成导航。
- **全文搜索**：内置搜索功能，便于发现内容。
- **优化的排版**：精心打磨的排版，提升可读性。
- **深色模式**：提供深色模式支持，满足用户偏好。
- **功能丰富**：深入探索该主题，充分领略其能力。
