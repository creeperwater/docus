## **从 Docus v3 迁移到 v4**

Docus v4 引入了全新的**基于层的方式**，改用官方 Nuxt CLI 取代原有的 Docus CLI。你现有的内容和配置仍然兼容，但需要更新命令和项目设置。

### **⚠️ 破坏性变更**

主要的破坏性变更与 CLI 命令相关：

| v3                       | v4                           |
| ------------------------ | ---------------------------- |
| `npx docus init my-docs` | `npx create-docus my-docs`   |
| `docus dev`              | `nuxt dev --extends docus`   |
| `docus build`            | `nuxt build --extends docus` |

::tip
你现有的 Markdown 内容和 MDC 语法无需修改即可正常工作。此次迁移主要涉及更新开发与构建流程。
::

## **迁移到 Docus**

已经在使用基于 Markdown 的文档方案？无论是 **Docus v1**、**Nuxt UI docs 模板**，还是其他静态站点方案，迁移到 Docus 都非常简单直接。

Docus 提供简洁且易维护的方案，只有一个依赖:Docus 库本身。无需管理多个依赖。所有功能内置且统一维护，让你的文档保持最新从未如此轻松。

要迁移，只需将现有的 Markdown 文件移动到 Docus 启动模板的 `content/` 目录中。

接下来有两种情况：

- **如果你当前的文档已在使用 Nuxt Content 和 MDC 语法**，请确认内容中用到的组件在 Nuxt UI 中存在。如有缺失的组件，你可以轻松创建自己的自定义组件。
- **如果你使用的是标准 Markdown**，可以直接原样复制文件。之后，再借助 Nuxt UI 提供的[内置组件](/zh-cn/essentials/components)逐步增强你的文档。

内容移入 `content/` 文件夹后，你可以浏览[配置章节](/zh-cn/concepts/configuration)，轻松自定义你的应用。

Docus 的设计理念就是专注于内容创作，因此如果你已经在使用 Markdown，可以非常轻松地切换到 Docus。
