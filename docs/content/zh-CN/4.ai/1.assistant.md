## 关于助手

助手通过自然语言查询回答关于你文档的问题。它直接嵌入在你的文档站点中，让用户能够快速找到答案，顺利上手你的产品。

当用户提问时，助手会：

- 通过 [MCP 服务器](/zh-cn/ai/mcp)**搜索并检索**你文档中的相关内容。
- **引用来源**，并附带可跳转的链接，直接将用户带到所引用的页面。
- **生成可复制的代码示例**，帮助用户根据文档实现解决方案。

## 工作原理

助手采用多 Agent 架构：

1. **Main Agent** - 接收用户问题，并决定何时搜索文档
2. **Search Agent** - 使用 [MCP 服务器](/zh-cn/ai/mcp)工具查找相关内容
3. **响应生成** - 将信息整合为有帮助的、对话式的回答

默认情况下，助手会连接到你文档内置的 MCP 服务器 `/mcp`，无需额外配置即可访问你的所有页面。如有需要，你也可以连接外部 MCP 服务器。

## 快速开始

::note{to="#custom-ai-provider"}
本快速开始使用 Vercel AI Gateway。若要使用其他提供商 (Mistral、OpenAI、Cloudflare AI Gateway，或 AI SDK 支持的任何其他提供商)，请参阅**自定义 AI 提供商**。
::

### 1. 配置 AI Gateway 身份验证

从以下方式中选择**一种**:

**API key**：在 [Vercel AI Gateway](https://vercel.com/~/ai/api-keys) 中创建一个密钥，并将其添加到你的环境变量中：

```bash [.env]
AI_GATEWAY_API_KEY=你的API密钥
```

**OIDC (仅限 Vercel)**:`VERCEL_OIDC_TOKEN` 会自动注入，因此在生产环境中无需添加任何内容。本地开发时，请在[已关联的项目](https://vercel.com/docs/cli/link)上运行 `vercel env pull`。

### 2. 部署

部署你的站点，身份验证配置完成后助手即可使用。

## 配置

通过 `app.config.ts` 配置助手：

```ts [app.config.ts]
export default defineAppConfig({
  assistant: {
    // 在文档页面上显示浮动输入框
    floatingInput: true,

    // 在侧边栏显示 "Explain with AI" 按钮
    explainWithAi: true,

    // 聊天为空时显示的常见问题
    faqQuestions: [],

    // 键盘快捷键
    shortcuts: {
      focusInput: 'meta_i'
    },

    // 自定义图标
    icons: {
      trigger: 'i-lucide-sparkles',
      explain: 'i-lucide-brain'
    }
  }
})
```

### 问题

在聊天为空时展示建议问题，帮助用户了解他们可以问什么。

#### 简单格式

```ts [app.config.ts]
export default defineAppConfig({
  assistant: {
    faqQuestions: [
      '如何安装 Docus?',
      '如何自定义主题?',
      '如何在页面中添加组件?'
    ]
  }
})
```

#### 分类格式

将问题组织到不同分类中：

```ts [app.config.ts]
export default defineAppConfig({
  assistant: {
    faqQuestions: [
      {
        category: '入门',
        items: [
          '如何安装 Docus?',
          '项目结构是什么样的?'
        ]
      },
      {
        category: '自定义',
        items: [
          '如何更改主题颜色?',
          '如何添加自定义 Logo?'
        ]
      }
    ]
  }
})
```

#### 本地化格式

对于多语言文档，可以按语言环境分别提供 FAQ 问题：

```ts [app.config.ts]
export default defineAppConfig({
  assistant: {
    faqQuestions: {
      en: [
        { category: 'Getting Started', items: ['How do I install?'] }
      ],
      fr: [
        { category: 'Démarrage', items: ['Comment installer ?'] }
      ]
    }
  }
})
```

### 键盘快捷键

配置聚焦浮动输入框的键盘快捷键：

```ts [app.config.ts]
export default defineAppConfig({
  assistant: {
    shortcuts: {
      // 默认:'meta_i'(Mac 上为 Cmd+I,Windows 上为 Ctrl+I)
      focusInput: 'meta_k' // 改为 Cmd/Ctrl+K
    }
  }
})
```

快捷键格式使用下划线分隔按键。常见示例：

- `meta_i` - Cmd+I(Mac)/ Ctrl+I(Windows)
- `meta_k` - Cmd+K(Mac)/ Ctrl+K(Windows)
- `ctrl_shift_p` - Ctrl+Shift+P

### 图标

自定义助手使用的图标：

```ts [app.config.ts]
export default defineAppConfig({
  assistant: {
    icons: {
      // 触发按钮与侧滑面板页头的图标
      trigger: 'i-lucide-bot',

      // "Explain with AI" 按钮的图标
      explain: 'i-lucide-lightbulb'
    }
  }
})
```

图标使用 [Iconify](https://iconify.design/) 格式 (例如 `i-lucide-sparkles`、`i-heroicons-sparkles`)。

### 功能

#### 禁用浮动输入框

隐藏文档页面底部的浮动输入框：

```ts [app.config.ts]
export default defineAppConfig({
  assistant: {
    floatingInput: false
  }
})
```

#### 禁用 "Explain with AI"

隐藏文档侧边栏中的 "Explain with AI" 按钮：

```ts [app.config.ts]
export default defineAppConfig({
  assistant: {
    explainWithAi: false
  }
})
```

#### 完全禁用助手

将 `enabled` 设为 `false` 即可禁用助手，即使 AI Gateway 凭据可用也不例外：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  docus: {
    assistant: {
      enabled: false
    }
  }
})
```

### MCP 服务器配置

助手使用 MCP 服务器访问你的文档。你有两个选择：

#### 使用内置 MCP 服务器 (默认)

默认情况下，助手使用 Docus 内置的 MCP 服务器 `/mcp`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  docus: {
    assistant: {
      mcpServer: '/mcp'
    }
  }
})
```

::warning
请确保你的配置中已启用 MCP 服务器。如果你自定义了 MCP 路径，请相应地更新 `mcpServer`。
::

#### 使用外部 MCP 服务器

提供完整 URL 即可连接任意外部 MCP 服务器：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  docus: {
    assistant: {
      mcpServer: 'https://other-docs.example.com/mcp'
    }
  }
})
```

当你希望助手基于另一个文档源回答问题，或连接到集中式知识库时，这非常有用。

### 模型

助手默认使用 `google/gemini-3-flash`。你可以将其更改为 AI SDK Gateway 支持的任意模型：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  docus: {
    assistant: {
      model: 'anthropic/claude-opus-4.5'
    }
  }
})
```

### 站点名称

助手会在回答中自动使用你的站点名称。在 `nuxt.config.ts` 中配置站点名称：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  site: {
    name: '我的文档'
  }
})
```

这会让助手以 "我的文档助手" 的身份回答问题，并以权威的口吻介绍你的具体产品。

## 自定义提供商

上面的 `model` 选项通过 Vercel AI Gateway 解析模型，因此需要 `AI_GATEWAY_API_KEY` 或 `VERCEL_OIDC_TOKEN`。若要使用其他提供商 (Mistral、OpenAI、Cloudflare AI Gateway，或 [AI SDK](https://ai-sdk.dev/) 支持的任何其他提供商)，请显式启用助手并提供你自己的端点。

::steps
### 启用助手并选择路径

设置 `enabled: true`，让助手不再依赖 AI Gateway 凭据，并将 `apiPath` 指向你即将创建的路由：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  docus: {
    assistant: {
      enabled: true,
      apiPath: '/api/assistant'
    }
  }
})
```

你自己的服务器路由始终具有优先权：当你在 `apiPath` 处定义路由后，Docus 会让出位置，不再在该处注册其内置端点。

### 安装提供商

安装你需要的 AI SDK 提供商包，例如 Mistral：

  :::code-group
  ```bash [npm]
  npm install @ai-sdk/mistral
  ```

  ```bash [pnpm]
  pnpm add @ai-sdk/mistral
  ```

  ```bash [yarn]
  yarn add @ai-sdk/mistral
  ```
  :::

### 实现端点

```ts [server/api/assistant.ts]
import { streamText, convertToModelMessages } from 'ai'
import { createMistral } from '@ai-sdk/mistral'

const mistral = createMistral()

export default defineEventHandler(async (event) => {
  const { messages } = await readBody(event)

  return createAssistantResponse(streamText({
    ...await getAssistantDefaultOptions(event),
    model: mistral('mistral-large-latest'),
    messages: await convertToModelMessages(messages)
  }))
})
```

  :::tip
  由于 `streamText` 调用由你掌控，提供商特有的约束可以在最合适的位置解决。
  :::

  :::warning
  默认值要放在展开运算符中**优先**展开。在展开之后设置的选项会生效 (之前的会被覆盖)。
  :::

| 工具函数                                                               | 作用                                                                                                                                                           |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`getAssistantDefaultOptions(event)`](#getassistantdefaultoptions) | 内置端点使用的全部 `streamText` 选项:MCP 工具、断开连接时中止生成、客户端清理、文档提示词，以及步数和 token 限制。 |
| [`getAssistantSystemPrompt(event)`](#getassistantsystemprompt)     | 单独返回默认的文档调优提示词，便于你在其基础上进行扩展。                                                                             |
| [`createAssistantResponse(result)`](#createassistantresponse)      | 将结果包装为助手 UI 所期望的响应格式。                                                                                              |

#### `getAssistantDefaultOptions`

返回真实的 `streamText` 选项，因此你可以查看并覆盖其中的每一项：

| 选项                   | 默认值                                                                                   |
| ------------------------ | ----------------------------------------------------------------------------------------- |
| `tools`                  | 来自 `docus.assistant.mcpServer` 的 MCP 工具                                            |
| `abortSignal`            | 客户端断开连接时中止生成                                             |
| `onEnd` / `onAbort`      | 关闭 MCP 客户端                                                                     |
| `onError`                | 在服务器端记录提供商错误，然后关闭 MCP 客户端                           |
| `instructions`           | `getAssistantSystemPrompt(event)`                                                         |
| `maxOutputTokens`        | `8000`                                                                                    |
| `maxRetries`             | `2`                                                                                       |
| `stopWhen`               | `isStepCount(10)`                                                                         |
| `prepareStep`            | 在最后一步禁用工具，让模型给出回答，而不是在工具调用中途停止 |
| `experimental_transform` | `smoothStream()`                                                                          |

`model` 和 `messages` 不包含在内，`providerOptions` 或 `temperature` 等提供商特有选项也不包含，因为它们无法跨提供商通用。

在展开之后设置选项即可覆盖默认值：

```ts [server/api/assistant.ts]
return createAssistantResponse(streamText({
  ...await getAssistantDefaultOptions(event),
  model: mistral('mistral-large-latest'),
  // 优先于默认的 8000
  maxOutputTokens: 4000,
  messages: await convertToModelMessages(messages)
}))
```

若要在回调中追加行为而不是替换它，请保留引用并继续调用原回调，这样 MCP 清理逻辑仍会执行：

```ts [server/api/assistant.ts]
const defaults = await getAssistantDefaultOptions(event)

return createAssistantResponse(streamText({
  ...defaults,
  model: mistral('mistral-large-latest'),
  messages: await convertToModelMessages(messages),
  onError: (payload) => {
    myErrorReporter(payload.error)
    // 仍会关闭 MCP 客户端
    defaults.onError(payload)
  }
}))
```

  :::warning
  `onEnd`、`onAbort` 和 `onError` 负责关闭 MCP 客户端。如果替换其中之一而没有调用原回调，每个请求都会泄漏一个连接。
  :::

#### `getAssistantSystemPrompt`

`getAssistantDefaultOptions` 已经将该提示词设置为 `instructions`，因此只有在需要扩展时才需要用到这个工具函数。它返回一个纯字符串，直接拼接即可：

```ts [server/api/assistant.ts]
const defaults = await getAssistantDefaultOptions(event)

return createAssistantResponse(streamText({
  ...defaults,
  model: mistral('mistral-large-latest'),
  messages: await convertToModelMessages(messages),
  instructions: `${defaults.instructions}

**额外指令:**
- 始终提及最低支持版本
- 绝不对路线图进行猜测`
}))
```

将 `instructions` 设置为你自己的字符串，即可完全替换默认提示词。

#### `createAssistantResponse`

将 `streamText` 的结果包装为助手 UI 所期望的响应格式，这样即使未来流格式发生变化，你的路由也无需修改即可跟进。
::

## 编程式访问

使用 `useAssistant` 组合式函数以编程方式控制助手：

```vue
<script setup>
const { isEnabled, isOpen, open, close, toggle } = useAssistant()

function askQuestion() {
  // 打开助手并预填一个问题
  open('如何配置主题?', true)
}
</script>

<template>
  <UButton v-if="isEnabled" @click="askQuestion">
    询问主题相关问题
  </UButton>
</template>
```

## 组合式函数 API

| 属性                         | 类型                   | 描述                                                                                                          |
| -------------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `isEnabled`                      | `ComputedRef<boolean>` | 助手是否已启用 (取决于 `docus.assistant.enabled`，或构建时的 `AI_GATEWAY_API_KEY` / `VERCEL_OIDC_TOKEN`) |
| `isOpen`                         | `Ref<boolean>`         | 侧滑面板是否已打开                                                                                        |
| `open(message?, clearPrevious?)` | `Function`             | 打开助手，可选携带一条消息                                                                        |
| `close()`                        | `Function`             | 关闭助手侧滑面板                                                                                        |
| `toggle()`                       | `Function`             | 切换助手的打开/关闭状态                                                                                     |
| `clearMessages()`                | `Function`             | 清除对话历史                                                                                       |
