## 关于 Agent 技能

Docus 会自动发现你 `skills/` 目录中的技能 (Skills)，并按照 [Cloudflare Agent Skills Discovery RFC](https://github.com/cloudflare/agent-skills-discovery-rfc) 在 `/.well-known/skills/` 路径下提供它们。这样，只需一条命令，你的技能就可以从任意文档 URL 安装。

[Agent Skills](https://agentskills.io/) 是一种轻量的开放格式，用于赋予 AI Agent 专业知识和工作流。一个技能就是一个带有 YAML frontmatter 的 `SKILL.md` 文件，描述 Agent 可以用你的产品做些什么，并可选地附带参考文件。

::note{to="https://docus.dev/.well-known/skills/index.json"}
查看本文档站点发布的技能。
::

## 快速开始

::steps
### 创建一个技能

在 Docus 项目根目录添加一个 `skills/` 目录，其中包含一个技能子目录，子目录中放置 `SKILL.md` 文件：

```bash
my-docs/
└── skills/
    └── my-product/
        └── SKILL.md
```

### 编写你的 SKILL.md

遵循 [agentskills.io 规范](https://agentskills.io/specification)。frontmatter 中唯一必填的字段是 `description`——如果省略 `name`，则默认使用目录名：

```md [skills/my-product/SKILL.md]
---
name: my-product
description: Build and deploy apps with My Product. Use when creating projects, configuring settings, or troubleshooting issues.
---

# My Product

## Getting Started

Create a new project:

\`\`\`bash
npx create-my-product my-app
\`\`\`
```

### 部署

部署你的文档。Docus 会自动在 `/.well-known/skills/` 路径下提供你的技能。

### 与用户分享

用户只需一条命令即可安装你的技能：

```bash
npx skills add https://your-docs-domain.com
```

CLI 会检测已安装的 Agent(Claude Code、Cursor、Windsurf 等)，并将技能安装到所有这些工具中。
::

## 目录结构

技能目录中除了 `SKILL.md` 之外，还可以包含辅助文件：

```bash
skills/
└── my-product/
    ├── SKILL.md              # 必需:说明 + 元数据
    ├── references/           # 可选:补充文档
    │   ├── api.md
    │   └── configuration.md
    ├── scripts/              # 可选:可执行代码
    │   └── setup.sh
    └── assets/               # 可选:模板、Schema
        └── config.template.yaml
```

所有文件都会自动列入 `index.json` 目录，并在 `/.well-known/skills/{skill-name}/` 下各自的路径中提供。

::tip
请将主 `SKILL.md` 保持在 500 行以内。把详细的参考资料移到 `references/` 中的独立文件里——Agent 会按需加载这些文件，文件越小，占用的上下文就越少。
::

## 配置

默认情况下，Docus 会在项目根目录的 `skills/` 目录中查找技能。你可以在 `nuxt.config.ts` 中通过 `agentDiscovery.skills.dir` 修改该目录，或将 `agentDiscovery.skills` 设为 `false` 以停止发布技能：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  agentDiscovery: {
    skills: {
      dir: 'agent-skills'
    }
  }
})
```

## 技能名称要求

技能名称必须遵循 [Agent Skills 命名规范](https://agentskills.io/specification#name-field):

- 1-64 个字符
- 仅限小写字母、数字和连字符 (`a-z`、`0-9`、`-`)
- 不能以连字符开头或结尾
- 不能包含连续的连字符 (`--`)
- frontmatter 中的 `name` 字段必须与父目录名一致

::note
未通过校验的技能会被跳过——请检查构建输出中的警告信息。
::

## 多个技能

你可以从同一个文档站点发布多个技能：

```bash
skills/
├── my-product/
│   └── SKILL.md
├── create-project/
│   ├── SKILL.md
│   └── references/
│       └── templates.md
└── migration-guide/
    └── SKILL.md
```

所有技能都会出现在 `index.json` 目录中，并且可以独立安装。

## 预览与版本控制

由于技能与文档一起存放在代码仓库中，它们可以直接受益于你现有的 Git 工作流：

- **分支预览**：在合并之前，于预览部署环境中测试技能变更。在 Vercel 上，每个 pull request 都会获得一个预览 URL，你可以在其中验证技能是否正常工作：

```bash
npx skills add https://my-docs-git-feat-new-skill.vercel.app
```

- **版本控制**：通过 Git 历史追踪技能变更，在 pull request 中审查差异，必要时回滚。
- **CI/CD**：技能随文档一起自动构建和部署——无需单独的发布步骤。

::tip
使用预览 URL 在正式发布到生产环境之前，用你的 AI 工具测试技能。这可以确保你的技能说明在真实 Agent 上正确运行。
::

## 发现机制如何工作

该功能实现了 [Cloudflare Agent Skills Discovery RFC](https://github.com/cloudflare/agent-skills-discovery-rfc)，它扩展了 [RFC 8615](https://datatracker.ietf.org/doc/html/rfc8615)(即 ACME 证书验证和 `security.txt` 背后使用的同一个 `.well-known` 标准)。

Docus 会在构建时扫描你的 `skills/` 目录，并生成两类端点：

### 发现索引

```
GET /.well-known/skills/index.json
```

返回一个 JSON 目录，列出所有可用技能及其描述和文件：

```json
{
  "skills": [
    {
      "name": "my-product",
      "description": "Build and deploy apps with My Product.",
      "files": ["SKILL.md", "references/api.md"]
    }
  ]
}
```

### 技能文件

```
GET /.well-known/skills/{skill-name}/SKILL.md
GET /.well-known/skills/{skill-name}/references/api.md
```

各个技能文件会以恰当的内容类型提供 (`.md` 文件为 `text/markdown`,`.json` 文件为 `application/json`，以此类推)。

## 与 llms.txt 的对比

`llms.txt` 和 Agent Skills 都能帮助 AI 工具使用你的文档，但它们的用途不同：

| | llms.txt | Agent Skills |
|---|---|---|
| **目的** | 所有文档页面的目录 | 带有可操作说明的能力概览 |
| **内容** | 页面标题、描述和链接 | 分步工作流、代码示例、约束条件 |
| **加载时机** | 发现时加载 | 按需加载，即技能被激活时 |
| **格式** | 带链接的纯文本 | 带 YAML frontmatter 的 Markdown |
| **最适合** | 帮助 Agent 查找信息 | 教会 Agent 如何使用你的产品 |

::tip
两者搭配使用效果更佳：`llms.txt` 告诉 Agent 去哪里查找信息，而技能则告诉 Agent 它们能完成什么以及如何完成。
::
