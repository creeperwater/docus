Prose 组件是 HTML 排版标签的替代品。它们提供了一种简单的方式，让你在使用 Markdown 时自定义界面。

**Docus 与 Nuxt UI** 提供了一套样式精美、开箱即用的 Prose 组件，帮助你使用 [MDC 语法](https://content.nuxt.com/docs/files/markdown#mdc-syntax)编写文档。

::note{to="https://ui.nuxt.com/getting-started"}
本页仅重点介绍最适合编写文档的 Prose 组件。不过，你可以在 Markdown 中使用**任何 Nuxt UI 组件**。完整的可用组件列表，请访问 Nuxt UI 文档。
::

### `Callout`

在 `callout` 组件的默认插槽中使用 Markdown，为内容添加醒目的提示信息。

使用 `icon` 和 `color` props 进行自定义。你也可以传入 `<NuxtLink>` 组件的任意属性。

你还可以使用 `note`、`tip`、`warning` 和 `caution` 快捷方式，它们预定义了图标和颜色。

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="预览"}
    ::::div{.flex.flex-col.gap-4.w-full}
      :::::note{.w-full.my-0}
      这里是一些补充信息。
      :::::

      :::::tip{.w-full.my-0}
      这里是一条实用的建议。
      :::::

      :::::warning{.w-full.my-0}
      请谨慎执行此操作，它可能产生意外的结果。
      :::::

      :::::caution{.w-full.my-0}
      此操作无法撤销。
      :::::
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="代码"}
```mdc
  ::note
  这里是一些补充信息。
  ::

  ::tip
  这里是一条实用的建议。
  ::

  ::warning
  请谨慎执行此操作，它可能产生意外的结果。
  ::

  ::caution
  此操作无法撤销。
  ::
```
  :::

### `Card` 与 `CardGroup`

使用 `title`、`icon` 和 `color` props 进行自定义。你也可以传入 `<NuxtLink>` 的任意属性。

用 `card-group` 组件包裹多个 `card` 组件，即可将它们组合成网格布局。

### `Collapsible`

::tabs

    ::::collapsible
    | Prop    | 默认值    | Type     |
    | ------- | --------- | -------- |
    | `name`  |           | `string` |
    | `size`  | `md`      | `string` |
    | `color` | `neutral` | `string` |
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="代码"}
```mdc
  ::collapsible

  | Prop    | 默认值    | Type                     |
  |---------|-----------|--------------------------|
  | `name`  |           | `string`{lang="ts-type"} |
  | `size`  | `md`      | `string`{lang="ts-type"} |
  | `color` | `neutral` | `string`{lang="ts-type"} |

  ::
```

### `Field` 与 `FieldGroup`

`field` 是要在内容中展示的 prop 或参数。你可以用 `field-group` 将它们组合成列表。

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="预览"}
    ::::field-group{.my-0}
      :::::field{name="analytics" type="boolean"}
      默认为 `false` - 为你的项目启用数据分析功能 (即将推出)。
      :::::

      :::::field{name="blob" type="boolean"}
      默认为 `false` - 启用 Blob 存储，用于存放图片、视频等静态资源。
      :::::

      :::::field{name="cache" type="boolean"}
      默认为 `false` - 启用缓存存储，使用 Nitro 的 `cachedEventHandler` 和 `cachedFunction` 缓存服务器路由响应或函数
      :::::

      :::::field{name="database" type="boolean"}
      默认为 `false` - 启用 SQL 数据库，用于存储应用的数据。
      :::::
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="代码"}
```mdc
  ::field-group
    ::field{name="analytics" type="boolean"}
      默认为 `false` - 为你的项目启用数据分析功能 (即将推出)。
    ::

  ::field{name="blob" type="boolean"}
    默认为 `false` - 启用 Blob 存储，用于存放图片、视频等静态资源。
  ::

  ::field{name="cache" type="boolean"}
    默认为 `false` - 启用缓存存储，使用 Nitro 的 `cachedEventHandler` 和 `cachedFunction` 缓存服务器路由响应或函数
  ::

  ::field{name="database" type="boolean"}
    默认为 `false` - 启用 SQL 数据库，用于存储应用的数据。
  ::
  ::
```

### `Steps`

用 Steps 组件包裹你的标题，即可展示步骤列表。

使用 `level` prop 指定将哪一级标题用作步骤。

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="预览"}
    ::::steps{level="4"}
    #### 创建一个全新项目

    ```bash [Terminal]
    npm create nuxt@latest -- -t github:nuxt-content/docus
    ```

    #### 运行 docus CLI 启动开发服务器

    ```bash [Terminal]
    docus dev
    ```
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="代码"}
````mdc
  ::steps{level="4"}
    #### 创建一个全新项目
    
    ```bash [Terminal]
    npm create nuxt@latest -- -t github:nuxt-content/docus
    ```
    
    #### 运行 docus CLI 启动开发服务器
    
    ```bash [Terminal]
    docus dev
    ```
  ::
````
