## Markdown

使用标准 Markdown 语法展示图片或视频。

### 图片

::code-preview
![Nuxt 社交图片](https://nuxt.com/new-social.jpg)

#code
```mdc
![Nuxt 社交图片](https://nuxt.com/new-social.jpg)
```
::

或使用你的本地图片

::code-preview
![日落云海中的雪山](/mountains.webp)

#code
```mdc
![日落云海中的雪山](/mountains.webp)
```
::

::note{to="https://image.nuxt.com/"}
Docus 底层会使用 `<NuxtImg>` 组件，而不是原生的 `img` 标签。
::
