### 代码块

使用代码块展示带语法高亮的多行代码片段。代码块是清晰呈现代码示例的必备元素。

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

#code
````mdc
```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```
````
::

编写代码块时，可以指定一个文件名，它将显示在代码块顶部。系统会根据文件扩展名或名称自动显示相应的图标。
文件名能帮助用户了解这段代码在项目中的位置与用途。

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```

#code
````mdc
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui']
})
```
````
::

每个代码块都内置复制按钮，可以将代码复制到剪贴板。

::tip{to="https://ui.nuxt.com/getting-started/icons/nuxt#theme"}
图标已有默认定义，你也可以在 `app.config.ts` 中自定义：

```ts [app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: 'i-ph-terminal-window-duotone'
      }
    }
  }
})
```
::



  ```bash [bun]

  ```

### CodeTree

使用 `code-tree` 以文件树视图展示代码块。`code-tree` 非常适合呈现项目结构和文件之间的关系。

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
  :::code-tree{default-value="app/app.config.ts"}
  ```ts [nuxt.config.ts]
  export default defineNuxtConfig({
    modules: ['@nuxt/ui'],

    future: {
      compatibilityVersion: 4
    },

    css: ['~/assets/css/main.css']
  })
  ```

  ```css [app/assets/css/main.css]
  @import "tailwindcss";
  @import "@nuxt/ui";
  ```

  ```ts [app/app.config.ts]
  export default defineAppConfig({
    ui: {
      colors: {
        primary: 'sky',
        colors: 'slate'
      }
    }
  })
  ```

  ```vue [app/app.vue]
  <template>
    <UApp>
      <NuxtPage />
    </UApp>
  </template>
  ```

  ```json [package.json]
  {
  ```
