## 标题

使用标题引出主要章节。标题为文档构建结构，帮助用户浏览内容。

::code-preview
---
class: "[&>div]:*:my-0"
---
## 标题

#code
```mdc
## 标题
```
::

### 副标题

使用副标题进一步细分章节，构建更细致的内容层级，提升可读性。

::code-preview
---
class: "[&>div]:*:my-0"
---
### 副标题

#code
```mdc
### 副标题
```
::

::tip
每个标题和副标题都会生成一个锚点，并自动显示在目录中。
::

## 文本格式化

Docus 支持大多数 Markdown 格式化选项。

| 样式  | 用法        | 效果      |
| --- | --------- | ------- |
| 加粗  | `**加粗**`  | **加粗**  |
| 斜体  | `*斜体*`    | *斜体*    |
| 删除线 | `~~删除线~~` | ~~删除线~~ |

组合使用格式化语法，可以获得更丰富的文本样式与视觉强调效果。

| 样式    | 用法           | 效果         |
| ----- | ------------ | ---------- |
| 加粗斜体  | `**_加粗斜体_**` | ***加粗斜体*** |
| 加粗删除线 | `~~**加粗**~~` | ~~**加粗**~~ |
| 斜体删除线 | `~~*斜体*~~`   | ~~*斜体*~~   |

## 链接

链接将文档的不同部分与外部资源连接起来，对于用户导航和提供参考资料至关重要。
创建链接时，将链接文本包裹在 `[]()` 中。

::code-preview
---
class: "[&>div]:*:my-0"
---
[Nuxt UI](https://ui.nuxt.com/getting-started/installation/nuxt)

#code
```mdc
[Nuxt UI](https://ui.nuxt.com/getting-started/installation/nuxt)
```
::

### 内部链接

在文档内部创建链接时，请使用相对于根目录的路径，例如 `/getting-started/installation`。

::code-preview
---
class: "[&>div]:*:my-0"
---
[Installation](/zh-cn/getting-started/installation)

#code
```mdc
[Installation](/zh-cn/getting-started/installation)
```
::

## 列表

以结构化、易读的格式组织相关内容。Markdown 支持无序列表、有序列表和嵌套列表，满足各种内容需求。

### 无序列表

无序列表用于没有特定顺序的条目。每个条目以 `-` 符号开头。

::code-preview
---
class: "[&>div]:*:my-0"
---
- 我是一个列表项。
- 我是另一个列表项。
- 我是最后一个列表项。

#code
```mdc
- 我是一个列表项。
- 我是另一个列表项。
- 我是最后一个列表项。
```
::

### 有序列表

当条目顺序很重要时 (例如操作流程中的步骤)，使用有序列表。每个条目以数字开头。

::code-preview
---
class: "[&>div]:*:my-0"
---
1. 我是一个列表项。
2. 我是另一个列表项。
3. 我是最后一个列表项。

#code
```mdc
1. 我是一个列表项。
2. 我是另一个列表项。
3. 我是最后一个列表项。
```
::

### 嵌套列表

通过子条目创建层级列表，以表达复杂结构。子条目缩进四个空格即可实现嵌套。

::code-preview
---
class: "[&>div]:*:my-0"
---
- 我是一个列表项。

  - 我是一个嵌套的列表项。
  - 我是另一个嵌套的列表项。
- 我是另一个列表项。

#code
```mdc
- 我是一个列表项。
  - 我是一个嵌套的列表项。
  - 我是另一个嵌套的列表项。
- 我是另一个列表项。
```
::

## 表格

以行和列的形式清晰呈现结构化数据。表格非常适合对比数据或罗列属性。

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
| Prop    | 默认值       | Type     |
| ------- | --------- | -------- |
| `name`  |           | `string` |
| `size`  | `md`      | `string` |
| `color` | `neutral` | `string` |

#code
```mdc
| Prop    | 默认值    | Type                     |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
::

## 块引用

突出显示重要的引文、出处或需要强调的文本。块引用能在视觉上区分引用内容。

### 单行

单行块引用适合简短有力、一行即可容纳的引文或出处。在段落前添加 `>` 即可创建单行块引用。非常适合简短而有冲击力的引用。

::code-preview
---
class: "[&>div]:*:my-0"
---
> Nuxt UI 是一个 Vue 组件、组合式函数与工具函数的集合，专注于结构与布局，旨在作为构建应用的基石。

#code
```mdc
> Nuxt UI 是一个 Vue 组件、组合式函数与工具函数的集合，专注于结构与布局，旨在作为构建应用的基石。
```
::

### 多行

多行块引用适合较长的引文，或需要在同一段引用中包含多个段落的情况。

::code-preview
---
class: "[&>div]:*:my-0"
---
> Nuxt UI 是一个 Vue 组件、组合式函数与工具函数的集合，专注于结构与布局，旨在作为构建应用的基石。
>
> 使用 Nuxt UI 创建美观、响应式且无障碍的 Vue 应用。

#code
```mdc
> Nuxt UI 是一个 Vue 组件、组合式函数与工具函数的集合，专注于结构与布局，旨在作为构建应用的基石。
>
> 使用 Nuxt UI 创建美观、响应式且无障碍的 Vue 应用。
```
::
